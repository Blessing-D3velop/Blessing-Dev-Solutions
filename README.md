# Blessing Dev Solutions 🌐

**My personal web development business and portfolio.**

🔗 **Live Website:** https://blessing-dev-solutions-sxcb.vercel.app/

Welcome to the repository for Blessing Dev Solutions!

I created this website to showcase my work as a web developer, share the services I offer, and give businesses an opportunity to see what I can build for them.

My goal is simple: help businesses establish a professional online presence through modern, responsive and functional websites that make it easier for customers to find them, learn about their services and get in touch.

This project is also something I continuously work on and improve as I learn new technologies and explore better ways of building websites.

## What the Website Offers

The website isn't just a portfolio. It also serves as the main platform for managing and presenting my web development services.

Some of its main features include:

- **Portfolio:** A collection of websites and projects I've worked on, with links to live projects.
- **Web Development Packages:** Different website development packages designed around different business needs.
- **Monthly Subscription Plans:** Recurring website service plans for clients who need ongoing support.
- **Payment Integration:** Subscription and package payment functionality.
- **Admin Dashboard:** A private dashboard where I can manage website packages, subscription plans and customer reviews.
- **Reviews System:** A section where clients can share feedback about my services.
- **Database Integration:** Supabase is used to store and manage relevant website data.
- **Content Management:** Dynamic content management for selected website sections.
- **Image Uploads:** API functionality for managing project images.
- **SEO Optimisation:** Search engine metadata, sitemap, robots.txt and Google site verification.
- **Responsive Design:** Designed to work across desktops, tablets and mobile devices.
